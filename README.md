## ⌨️ Presentation Keyboard Shortcuts

When viewing the live deck:
- **`Right Arrow` / `Space` / `PageDown`**: Next slide
- **`Left Arrow` / `PageUp`**: Previous slide
- **`N`**: Toggle **Speaker Notes Drawer** (real-time script & talking points for each presenter)
- **`F`**: Toggle **Fullscreen Mode**
- **`P`**: Print or Save as PDF (formatted cleanly for 16:9 landscape)
- **`Home` / `End`**: Jump to first / last slide
